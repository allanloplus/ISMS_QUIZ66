# ISMS 課程課後測驗網站

學員參加實體或線上 ISMS 課程後，到本網站做課後測驗。通過的學員可以下載合格證書，證書附有測驗題目與解答；沒通過的學員要重新上課、閱讀教材，或重新測驗。

課程講師：羅宇倫 Allan Lo

## 架構

```
學員／管理者瀏覽器
   │  https://allanloplus.github.io/ISMS_QUIZ66/   ← GitHub Pages（docs/ 資料夾）
   ▼
Google Apps Script 網頁應用程式（apps-script/Code.gs） ← 負責評分、登入、讀寫資料
   ▼
Google 試算表（您的 Google 雲端硬碟）       ← 存放課程、題庫、測驗紀錄
```

- 不需要租主機，也不用維護伺服器，完全免費。
- 評分在 Google 端進行，學員的瀏覽器拿不到答案。
- 測驗紀錄存在您自己的 Google 試算表，可以直接篩選或下載成 Excel。

## 安裝步驟（約 15 分鐘，只需做一次）

### 步驟 1：建立 Google 試算表與後端程式

1. 用您的 Google 帳號開啟 <https://sheets.new> 建立新試算表，命名為「ISMS 課程測驗資料庫」。
2. 點選上方選單 **擴充功能 → Apps Script**，會開啟程式編輯器。
3. 把編輯器裡原本的程式碼（`function myFunction() {}`）**全部刪掉**。
4. 打開本專案的 [`apps-script/Code.gs`](apps-script/Code.gs)，按右上角的「Copy raw file」複製全部內容，貼到編輯器。
5. 按 **儲存**（磁碟圖示或 Ctrl+S）。左上角的專案名稱可以改成「ISMS 課程測驗」。

### 步驟 2：初始化（建立工作表與範例資料）

1. 編輯器上方的函式選單選 **`setup`**，按 **▶ 執行**。
2. 第一次執行時 Google 會要求授權：
   - 按「審查權限」並選擇您的帳號。
   - 如果出現「Google 尚未驗證這個應用程式」，請點 **進階** →「**前往 ISMS 課程測驗（不安全）**」→ **允許**。
   - 這是因為程式是您自己貼上的，還沒經過 Google 審查，屬於正常現象。程式只會存取這一份試算表。
3. 執行完成後回到試算表，會看到 5 個工作表：「設定、課程類別、課程、題庫、測驗紀錄」，還有兩門範例課程。

### 步驟 3：部署為網頁應用程式

1. 在 Apps Script 編輯器右上角按 **部署 → 新增部署作業**。
2. 按「選取類型」旁的齒輪 ⚙，選 **網頁應用程式**。
3. 依下表設定：

   | 欄位 | 設定 |
   |---|---|
   | 說明 | ISMS 課程測驗 v1 |
   | 執行身分 | **我** |
   | 誰可以存取 | **所有人** |

4. 按 **部署**，複製畫面上的「**網頁應用程式網址**」，格式為 `https://script.google.com/macros/s/……/exec`。
5. （可選）把網址貼到瀏覽器開啟，看到 `{"ok":true,"data":{"service":"ISMS Quiz API","status":"running"}}` 就代表成功。

> 選「所有人」是為了讓學員不必登入 Google 就能作答。後台功能仍然需要管理密碼。試算表本身維持私人，**請勿分享試算表**。
> 如果您用的是公司的 Google Workspace 帳號，又看不到「所有人」選項，代表公司管理員限制了這個設定，請改用個人 Gmail 帳號。

### 步驟 4：把後端網址填進 GitHub

1. 在 GitHub 打開本專案的 [`docs/js/config.js`](docs/js/config.js)，按右上角的鉛筆圖示（Edit）。
2. 把網址貼到引號中：

   ```js
   window.ISMS_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/……/exec',
   };
   ```

3. 按 **Commit changes** 儲存。

### 步驟 5：開啟 GitHub Pages

1. 到 GitHub 專案的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**。
3. Branch 選放程式的分支（目前是 `claude/jolly-goodall-qtb0k5`；之後若合併到 `main` 就改選 `main`），資料夾選 **`/docs`**，按 **Save**。
4. 等 1～2 分鐘，網站會出現在：**https://allanloplus.github.io/ISMS_QUIZ66/**

### 步驟 6：登入後台並變更密碼

1. 開啟 **https://allanloplus.github.io/ISMS_QUIZ66/admin.html**
2. 用預設密碼 `admin1234` 登入，然後到「**系統設定**」**立即變更密碼**。
3. 在「課程與題庫」修改或刪除範例課程，加入您自己的課程與題目。

## 日常使用

| 我要… | 怎麼做 |
|---|---|
| 新增課程、編輯題庫、調整配分 | 後台 → 課程與題庫 |
| 讓學員開始測驗 | 在課程勾選「開放前台測驗」，再把首頁或課程網址給學員 |
| 查看誰通過、匯出名單 | 後台 → 測驗紀錄 →「匯出 CSV」，也可以直接打開試算表的「測驗紀錄」工作表 |
| 補發證書給學員 | 後台 → 測驗紀錄 → 該筆紀錄的「證書」按鈕，把網址寄給學員 |
| 查驗證書真偽 | 前台「證書查驗」，輸入證書編號 |
| 更換或新增講師簽名 | 把去背 PNG 放到 `docs/img/`，再到 `docs/js/config.js` 的 `SIGNATURES` 加一行 `'講師姓名': 'img/檔名.png'`。只要課程的講師名稱包含該姓名，證書就會顯示簽名 |
| 忘記管理密碼 | 在 Apps Script 編輯器選 `resetAdminPassword` 後按執行，密碼會重設為 `admin1234` |

## 更新後端程式時（重要）

`Code.gs` 有更新時，貼上新程式並儲存**還不會生效**，要再發佈新版本：

**部署 → 管理部署作業 → 鉛筆圖示（編輯）→ 版本選「新版本」→ 部署**

這樣做網址不會改變，不需要修改 `config.js`。如果改用「新增部署作業」，會產生新的網址。

## 功能清單

**前台（學員）**
- 依課程類別（資安宣導、專業課程…）選擇課程
- 填寫公司名稱、單位、姓名、職稱、E-mail，並同意個資蒐集告知（依個資法第 8 條，告知文字可在後台修改）
- 線上作答（單選／複選／是非），顯示作答進度；交卷前會提醒未作答的題目
- **通過**：產生合格證書，可下載 PNG 圖片或列印／另存 PDF。PDF 第 1 頁是 A4 橫式證書，後面附上全部題目、正確答案、學員作答與解析
- **未通過**：只顯示分數，不公布答案；提示重新上課或閱讀教材，並可重新測驗
- 證書查驗：輸入證書編號即可查驗真偽，姓名遮罩顯示

**後台（`admin.html`）**
- 課程：類別、名稱、上課日期、講師、上課方式、時數、說明、教材連結、及格分數、是否開放
- 題庫：新增、複製、排序、刪除題目，設定答案、配分與解析；題目和選項可設定亂序；可匯出／匯入 JSON
- 分數分配：每題可個別配分，也可「平均分配總分」，會即時顯示總分與及格比例
- 測驗紀錄：查詢、通過率統計、匯出 CSV、開啟證書、刪除（因應個資刪除請求）
- 課程類別管理、系統設定（網站名稱、發證單位、證書標題、證書編號字軌、預設講師、個資告知文字）、變更密碼

## 安全與限制說明

- 管理密碼以加鹽雜湊存在 Apps Script「指令碼屬性」，不存在試算表裡。登入連續失敗 10 次會暫停 15 分鐘；登入狀態最長維持 6 小時。
- 證書網址含隨機權杖，只有持有連結的人才能檢視。
- 寫入試算表的文字會加上前置單引號，避免被當成公式執行；匯出的 CSV 也已防範公式注入。
- 已發出的證書保存作答當下的題目快照，之後修改題庫不會影響既有證書。
- Google Apps Script 每次回應約需 1～3 秒，同時執行數有上限（一般帳號約 30 個）。一般課程規模，例如數十人在課後陸續作答，不會有問題。
- 單一課程的題庫大小受試算表儲存格 5 萬字元限制，約可放 80～100 題；超過時請拆成多個課程。
- 講師簽名圖檔放在公開網站上，任何人都能下載。證書的真偽請以「證書查驗」頁核對證書編號為準。
- 學員個資存放在您的 Google 帳號中，請依組織的個資保護規範管理存取權限與保存期限。

## 開發者：本機預覽與測試

需要 Node.js 18 以上，不需要安裝任何套件。

```bash
npm test          # 以模擬的 Google 環境測試 Code.gs
npm run dev       # 本機預覽 http://localhost:8080（資料只存在記憶體，後台密碼 admin1234）
```

| 路徑 | 說明 |
|---|---|
| `docs/` | GitHub Pages 網站（前台、後台、證書、查驗頁） |
| `docs/js/config.js` | 後端網址設定 |
| `apps-script/Code.gs` | Google Apps Script 後端（貼到試算表的 Apps Script） |
| `tools/` | 本機預覽伺服器與 Google 環境模擬 |
| `test/` | 自動化測試 |
