# ISMS 課程課後測驗網站

學員參加實體或線上 ISMS 課程後，至本網站進行課後測驗；通過者可下載合格證書（附測驗題目與解答），未通過者需重新上課／閱讀教材或重新測驗。

課程講師：羅宇倫 Allan Lo

## 功能

**前台（學員）**
- 依課程類別（資安宣導、專業課程…）瀏覽並選擇要測驗的課程
- 填寫公司名稱、單位、姓名、職稱、E-mail，並勾選個資蒐集告知同意
- 線上作答（單選／複選／是非），顯示作答進度，交卷前提醒未作答題目
- **通過**：產生合格證書（證書編號、成績、講師），可「下載證書圖片 PNG」或「列印／另存 PDF」，PDF 附件含全部題目、正確答案、學員作答與解析
- **未通過**：顯示分數，不公布答案；提示重新上課或閱讀教材（後台可設定教材連結），並可重新測驗
- 證書查驗頁：輸入證書編號即可查驗真偽（姓名遮罩顯示）

**後台（管理者，`/admin.html`）**
- 課程管理：類別、課程名稱、上課日期、講師、上課方式、時數、說明、教材連結、及格分數、是否開放
- 題庫編輯：新增／複製／排序／刪除題目，設定正確答案、每題配分與解析；題目／選項亂序
- 分數分配：每題個別配分，或一鍵「平均分配總分」；即時顯示總分與及格比例
- 題庫 JSON 匯出／匯入、課程複製
- 測驗紀錄：依課程／結果／關鍵字查詢，通過率統計，匯出 CSV（Excel 可直接開啟），開啟學員證書，刪除紀錄（因應當事人刪除請求）
- 課程類別管理、系統設定（網站名稱、發證單位、證書標題、證書編號字軌、預設講師、個資告知文字）、變更管理密碼

## 啟動

需求：Node.js 18 以上。

```bash
npm install
ADMIN_PASSWORD='請設定強密碼' npm start
# 前台 http://localhost:3000
# 後台 http://localhost:3000/admin.html
```

未設定 `ADMIN_PASSWORD` 時，首次啟動的管理密碼為 `admin1234`，後台會提示立即變更。密碼僅於首次建立資料時套用，之後請於後台「系統設定」變更。

| 環境變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 服務埠號 | `3000` |
| `DATA_DIR` | 資料目錄（`db.json`） | `./data` |
| `ADMIN_PASSWORD` | 首次啟動的管理密碼 | `admin1234` |
| `TRUST_PROXY` | 位於反向代理後方時設定（例如 `1`），使 IP 與 HTTPS 判斷正確 | 未設定 |

Docker：

```bash
docker build -t isms-quiz .
docker run -d -p 3000:3000 -v isms-quiz-data:/data -e ADMIN_PASSWORD='請設定強密碼' isms-quiz
```

首次啟動會建立兩門範例課程（資訊安全意識宣導、ISO/IEC 27001:2022 條文解析），各 10 題，可於後台修改或刪除。

## 資料與安全說明

- 所有資料存於 `DATA_DIR/db.json`，請納入備份。學員個資屬個人資料，請依組織之個資保護規範管理存取與保存期限。
- 正式上線請置於 HTTPS（反向代理如 Nginx／Caddy）之後，並設定 `TRUST_PROXY`。
- 題目答案只在伺服器端評分，前台作答時不會下傳答案；證書連結含隨機權杖，僅持有連結者可檢視。
- 後台密碼以 scrypt 雜湊保存；連續登入失敗 5 次鎖定 15 分鐘；Session 為 HttpOnly + SameSite=Strict Cookie。
- 匯出 CSV 已防範公式注入（CSV injection）。
- 已發出的證書保存作答當下的題目快照，日後修改題庫不影響既有證書內容。
